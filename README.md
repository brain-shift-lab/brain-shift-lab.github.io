# Signal Shift

เกมอาร์เคดฝึกสมองแบบสลับกฎ (task switching) สำหรับเล่นบนเว็บ ภาษาไทย/อังกฤษ

- **เล่นอาร์เคด**: ด่านเพิ่มกฎทีละข้อ (สี → รูปทรง → สลับกฎ → สัญญาณหยุด → ความจำ 1 ย้อนหลัง) มีบอสทุก 5 ด่าน
- **ภารกิจประจำวัน**: ทุกคนได้โจทย์ 40 ข้อชุดเดียวกันในแต่ละวัน (เวลาไทย) แข่งกันบนตารางอันดับรายวัน
- **ตารางอันดับ**: รายวัน และอาร์เคดตลอดกาล ตั้งชื่อเองได้ ไม่ต้องสมัครสมาชิก
- **ความก้าวหน้า**: กราฟต้นทุนการสลับกฎ เวลาตอบสนอง และความแม่นยำ เก็บในเบราว์เซอร์ของผู้เล่น
- **โหมดวิจัย**: โปรโตคอลมาตรฐาน ~170 ข้อ บันทึกรายข้อ (RT เป็นมิลลิวินาที) ส่งเข้า Google Sheet

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด |
| `config.js` | URL ของ Google Apps Script (ที่เก็บคะแนนและข้อมูลวิจัย) |
| `Code.gs` | สำเนาโค้ดฝั่ง Google Apps Script (ตัวจริงอยู่ในชีต Signal Shift Data → ส่วนขยาย → Apps Script) |

## ข้อมูลไปอยู่ที่ไหน

Google Sheet **Signal Shift Data** ของเจ้าของโปรเจกต์ มี 3 แผ่นงาน
- `scores` คะแนนทุกครั้งที่มีคนส่งขึ้นตารางอันดับ
- `runs` สรุปผลโหมดวิจัย 1 แถวต่อ 1 ครั้งทดสอบ
- `trials` ข้อมูลรายข้อของโหมดวิจัย (ใช้คอลัมน์ `runId` จับคู่กับ `runs`)

## แก้ไขหรืออัปเดต

- เปลี่ยนที่เก็บข้อมูล: แก้ `backendUrl` ใน `config.js`
- ถ้าแก้ `Code.gs` ใน Apps Script ต้องกด **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมจะใช้ต่อได้
- GitHub Pages อัปเดตเว็บเองภายใน 1–2 นาทีหลังแก้ไฟล์

## หมายเหตุ

ตารางอันดับตรวจคะแนนแบบหยาบ (จำกัดเพดานคะแนน จำกัดความถี่ส่ง) เหมาะกับการเล่นในกลุ่ม ไม่เหมาะกับการแข่งที่มีรางวัล ข้อมูลโหมดวิจัยไม่มีชื่อหรือข้อมูลส่วนตัว มีเพียงรหัสผู้เข้าร่วมที่ผู้วิจัยกำหนด
